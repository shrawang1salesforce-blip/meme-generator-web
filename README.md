# MemeGenerator

A small, browser-based meme editor. It uses the Canvas API, so your uploaded photos stay on your device.

## Run it

Open `index.html` in a browser. No install or build step is needed.

Choose a photo from your device or use the sample image, edit the top and bottom lines, then select **Download image** to save a PNG. The sample image and web fonts need an internet connection; uploading and exporting your own image works locally.
